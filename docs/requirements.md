# nav-guide 网址导航主页 — 需求方案

> 版本 v1.0 · 2026-08-21 · 状态：需求已定稿，待实现

## 1. 产品定位

浏览器主页 / 新标签页。用户每次打开浏览器第一眼看到的页面。

核心诉求：
- **快速搜索** —— 聚合多引擎，输入即达
- **一键到达** —— 常用网站按分类平铺，单击打开
- **本地运行** —— 数据与运行全部本地化，无第三方服务依赖

## 2. 技术形态（已定，不可更改）

| 项 | 决策 |
|---|---|
| 交付物 | 单文件 `index.html` |
| 依赖 | 零依赖、零构建，`file://` 双击直接可用 |
| 技术栈 | 原生 HTML + CSS + JS（ES2020，无框架） |
| 数据 | 网址写死在文件顶部的 `CONFIG` 对象，带注释 |
| 网络请求 | 仅 favicon（`https://域名/favicon.ico`）与搜索引擎跳转，页面本身离线可用 |
| 字体 | 系统字体栈，不引入 web font |

## 3. 功能需求

### 3.1 聚合搜索框
- 位于页面视觉中心，大尺寸输入框
- 内置引擎：Google / Bing / 百度 / DuckDuckGo
- **切换方式**：`Tab` 键循环切换，或点击引擎名称切换
- 记住上次选择的引擎（localStorage，键名 `nav-engine`）
- 回车在新标签页打开搜索结果（`window.open`）
- 页面加载后光标自动聚焦搜索框；任意时刻按 `/` 回到搜索框

### 3.2 网址分区
- 按分类组织，默认四类：**常用、开发、工具、娱乐**
- 每个站点渲染为卡片：图标 + 名称
- 悬停显示 `title`（描述 + 完整域名）
- 点击在新标签页打开（`target="_blank"` + `rel="noopener"`）
- 分类数据结构：

```js
CONFIG.categories = [
  {
    name: "常用",
    sites: [
      { name: "GitHub", url: "https://github.com", desc: "代码托管", icon: "" /* 可选，留空自动取 favicon */ },
    ],
  },
];
```

### 3.3 网站图标（三级策略）
1. 配置显式填写 `icon` URL → 直接使用
2. 未填 → 自动 `https://域名/favicon.ico`
3. 加载失败 → 降级为首字母彩色圆形占位图标（颜色由站名 hash 决定，保证稳定）

### 3.4 暗色模式
- 三态逻辑：`auto`（默认，跟随 `prefers-color-scheme`）→ `light` → `dark`，按钮循环切换
- 偏好存 localStorage（键名 `nav-theme`）
- `auto` 态下监听系统主题变化实时切换

### 3.5 响应式布局
- 卡片网格：`auto-fill, minmax(150px, 1fr)` 自适应列数
- 搜索框与网格最大宽度 1200px 居中
- 移动端可用（点击为主，无 hover 依赖的关键功能）

## 4. 视觉设计规格（玻璃拟态）

### 4.1 背景光斑（纯 CSS）
- 浅色：奶油底色 + 3~4 个大尺寸彩色 radial-gradient 光斑（杏色/玫瑰/天蓝），缓慢漂移动画（60s，`prefers-reduced-motion` 时禁用）
- 深色：深蓝黑底 + 霓虹光斑（紫/青/品红），透明度更低

### 4.2 玻璃卡片 token

| Token | 浅色 | 深色 |
|---|---|---|
| `--glass-bg` | `rgba(255,255,255,0.55)` | `rgba(30,32,44,0.55)` |
| `--glass-border` | `rgba(255,255,255,0.65)` | `rgba(255,255,255,0.12)` |
| `--glass-blur` | `16px` | `16px` |
| `--glass-shadow` | `0 8px 32px rgba(31,38,135,0.12)` | `0 8px 32px rgba(0,0,0,0.45)` |
| `--text-1` / `--text-2` | `#1f2330` / `#5a6072` | `#eef0f6` / `#9aa0b4` |
| `--accent` | `#6366f1`（靛蓝） | `#818cf8` |

### 4.3 组件规格
- **搜索框**：高 56~64px 圆胶囊，玻璃底；左引擎名（可点）+ 输入区 + 右回车提示；focus 时边框转 accent 色 + 外发光
- **网址卡片**：`border-radius: 16px`，图标 32px 圆角方块（白底微缩），名称 14px；hover 上浮 2px + 阴影增强
- **分类标题**：小字号（13px）+ 字距拉宽（`letter-spacing: 0.08em`）+ 前置短横线装饰
- **主题按钮**：右上角固定，玻璃圆形按钮，图标随三态变化（🔄/☀️/🌙 或 SVG）

## 5. 交互细节汇总

| 触发 | 行为 |
|---|---|
| 页面加载 | 聚焦搜索框，恢复引擎与主题偏好 |
| `Tab`（在搜索框内） | 切换搜索引擎 |
| `/`（全局） | 聚焦搜索框（并阻止默认行为） |
| `Enter`（搜索框内） | 新标签页打开搜索结果 |
| 点击网址卡片 | 新标签页打开站点 |
| 点击主题按钮 | auto → light → dark 循环 |

## 6. CONFIG 完整结构（默认配置）

```js
const CONFIG = {
  title: "导航",
  background: "",          // 可选：自定义壁纸 URL，留空用默认渐变光斑
  engines: [               // name + searchUrl（含 %s 占位符）
    { name: "Google", url: "https://www.google.com/search?q=%s" },
    { name: "Bing",   url: "https://www.bing.com/search?q=%s" },
    { name: "百度",   url: "https://www.baidu.com/s?wd=%s" },
    { name: "DuckDuckGo", url: "https://duckduckgo.com/?q=%s" },
  ],
  categories: [ /* 见 3.2 */ ],
};
```

# v1.1 增补 — Chrome 扩展形态（2026-08-24）

> v1.0 的"单文件"约束升级为"项目根目录即扩展根目录"：`index.html` 仍可 `file://` 双击独立使用，
> 但内联脚本因 MV3 CSP 限制拆分为 `common.js` + `index.js` 两个外部文件。

## 1. 交付物

| 文件 | 职责 |
|---|---|
| `manifest.json` | MV3 清单；`chrome_url_overrides.newtab` 接管新标签页 |
| `index.html` + `index.js` + `common.js` | 导航页（新标签页 / file:// 双环境自适应） |
| `popup.html` + `popup.js` | 扩展图标弹窗：收藏/编辑当前页 |
| `background.js` | 右键菜单「添加到导航」快捷收藏 |
| `icons/icon{16,48,128}.png` | 扩展图标 |

权限：`storage`、`activeTab`、`contextMenus`（无浏览历史等敏感权限提示）。

## 2. 数据模型

`chrome.storage.local` 单键 `navSites`：

```js
[{ id, name, url, desc, icon, account, category, addedAt }]
```

- `account`：自由文本备注（如"账号 xxx@x.com / 密码提示：生日"），明文仅存本机，不上传
- 渲染 = CONFIG 默认分类 + 用户站点按 `category` 合并（新分类追加为新区块）
- 主题/引擎偏好仍走 localStorage，与 v1.0 一致
- file:// 环境无扩展 API → 纯 CONFIG 只读展示，行为与 v1.0 完全一致

## 3. 功能需求

1. **新标签页接管**：打开新标签页显示导航页
2. **popup 收藏**：浏览任意网页点击扩展图标 → 自动带出标题/网址/favicon → 选分类（默认四类/已有自定义/新建）、填描述与账号信息 → 保存；已收藏的网址进入编辑模式（更新/移除）；URL 规范化去重（去 hash、去尾部斜杠）
3. **右键快捷添加**：网页右键「添加到导航」→ 收藏到「快速收藏」分类，扩展图标 badge 显示 ✓/!；选中文本可作为站点名
4. **导航页编辑**：用户添加的卡片 hover 出现 ⋯ 按钮 → 玻璃拟态模态框编辑（名称/网址/分类/描述/账号）+ 二次确认删除；默认 CONFIG 卡片不可编辑
5. **账号信息展示**：有 `account` 的卡片名称旁显示 👤 角标；hover title 显示「描述 · 域名 · 账号信息」
6. **即时刷新**：`chrome.storage.onChanged` 监听，popup/右键添加后已打开的导航页自动重渲染

## 4. 安装

`chrome://extensions` → 开发者模式 → 加载已解压的扩展程序 → 选择本项目根目录。

## 5. v1.1 验收（已自动化验证 26/26 通过）

- 扩展环境：页面加载、chrome.storage 可用、24 张默认卡片、无 JS 报错
- 数据链路：storage 写入 → onChanged 自动重渲染 → 新分类区块出现
- 账号信息：角标显示、title 含账号、模态框回填、编辑保存落盘
- 删除：二次确认、卡片移除、storage 同步
- popup：加载无异常、非法页面显示不可收藏提示、明暗主题跟随系统
- file:// 回归：标题/只读分支/24 张卡片/无编辑按钮，与 v1.0 行为一致

# v1.2 增补 — 体验闭环（2026-08-25）

> 对应产品评审结论：把「一次收藏」的丝滑延伸到「一百次收藏之后」——搜索、组织、迁移、移动端四条主线。

## 1. 搜索框升级（P0）

- **过滤收藏**：输入即按 名称/描述/域名/网址 过滤卡片，空分类整节隐藏；无匹配时显示「没有匹配的收藏，回车将用引擎搜索」提示
- **URL 直达**：输入 `github.com` / `https://…` / `localhost:3000` 等直接新标签打开；末段为两字符 TLD 时需命中白名单（避免 `node.js` 误判）
- 键盘：`↓` 从搜索框进入过滤后首张卡片；`Esc` 清空过滤；`Shift+Tab` 放行（修复键盘陷阱）；`/` 不再劫持输入态/模态框内的按键

## 2. 收藏管理闭环（P1）

- **页内添加**：右上角 `+` 打开「添加站点」模态框（复用编辑模态框），file:// 环境隐藏
- **默认卡片可隐藏**：hover 显示 `✕` → 隐藏 + toast 撤销；设置菜单「恢复默认卡片」一键还原；空分类不渲染
- **分类管理**：设置菜单 → 重命名（同名即合并）/ 删除（站点移入「快速收藏」）
- **导出/导入**：JSON 备份全部用户站点（含账号备注）；导入按规范化 URL 合并（同址更新、新址追加、无效跳过），toast 汇报结果
- **模态框增强**：支持「＋ 新建分类…」（与 popup 对齐）；编辑时改 URL 后自动丢弃旧 favicon 并做重复校验（含默认卡片）

## 3. 组织与回访（P2）

- **置顶**：编辑模态框内切换，置顶站点稳定排序到分类顶部
- **最近使用**：任意卡片点击记录（上限 12 条），首页顶部展示「最近使用」区块；过滤中隐藏；已隐藏的默认站不再出现
- **账号信息防肩窥**：hover title 移除账号；点击 `👤` 弹层查看，点外部关闭

## 4. 反馈与触屏（P0/P1）

- **toast 系统**：隐藏/导入/外部添加等操作的即时反馈，支持「撤销」动作按钮
- **外部添加提示**：popup/右键收藏后，已打开的导航页 toast「已添加「x」到「y」」
- **右键 badge 文案**：成功 `✓`、重复 `已有`(琥珀)、不支持 `✗`(红)
- **触屏适配**：`@media (hover: none)` 下编辑/隐藏按钮常显，触屏设备可管理收藏

## 5. 数据模型变更

`navSites` 记录新增 `pinned?: boolean`；新增存储键 `navHiddenDefaults`(隐藏的默认站 normalized url 数组)、`navRecent`(最近使用)。popup 记住上次使用的分类（localStorage `nav-last-cat`）。

## 6. 验收（自动化 66 项断言全通过，脚本见 `tests/`）

- 功能 59 项：过滤/直达/TLD 白名单、键盘（Tab/Shift+Tab/`/`/Esc/↓）、添加/编辑/删除/置顶/新建分类、重复校验、隐藏+撤销+恢复、分类重命名合并删除、导出/导入合并、最近使用、账号弹层、外部添加 toast、file:// 回归
- 布局 7 项：无横向溢出、工具栏对齐、模态框居中、移动端视口、触屏按钮常显规则存在
- 触屏常显规则的运行时验证受无头桌面环境限制（恒报 hover:hover），已通过规则注入验证 CSS 生效

# v1.3 增补 — 分类悬浮导航、_self 打开与全局分类管理（2026-08-28）

## 1. 核心需求点

1. **左侧悬浮分类组件（Scrollspy）**：
   - 当分类数较多时，左侧以毛玻璃拟态悬浮展示分类快速导航列表；
   - 点击平滑滚动至对应分类区块；
   - 监听页面滚动实时自动高亮当前所在分类（Scrollspy）；
   - 搜索过滤时自适应更新/隐藏；窄屏（< 1200px）与移动端自动隐藏防遮挡。
2. **链接默认 `target="_self"`**：
   - 导航页内网址卡片默认在当前窗口直接打开（`target="_self"`）。
3. **全量分类管理与自定义排序**：
   - 统一管理所有分类（内置默认分类“常用、开发、工具、娱乐”与所有自定义分类）；
   - 支持拖拽手柄 `⠿` 或 `▲` / `▼` 按钮自由调整分类显示顺序；
   - 支持对任意分类进行重命名（同步更新对应站点，同名自动合并）；
   - 支持删除分类（分类删除后其下站点自动移入「快速收藏」）；
   - 支持直接新建分类与一键「恢复默认分类」；
   - 新增存储键 `navCategoryOrder`（分类排序数组）与 `navCategoryMap`（默认分类重命名映射），由 `navStorage` 自动双写并支持 Google Sync 多端云同步。

- 功能 74 项（含左侧悬浮导航联动、target _self、全量分类排序/重命名/删除/新建/恢复）
- 布局 11 项（含桌面宽屏侧边栏定位、移动端自适应隐藏等）
