# nav-guide 网址导航主页 — 页面设计与交互规范

> 版本：v1.0 · 设计目标：轻量、极简、沉浸式毛玻璃拟态（Glassmorphism）

---

## 1. 设计概述与设计语言

### 1.1 整体调性
- **轻量通透**：采用柔和的背景渐变光斑 + 毛玻璃质感（Backdrop Filter Blur），呈现呼吸感与层次感。
- **高效极简**：居中聚合搜索框与分类平铺卡片，减少视觉噪音，强化键盘快捷操作（`/` 聚焦、`Tab` 换源、`Enter` 直达）。
- **零依赖原生美学**：依托现代 CSS 原生能力（CSS 变量、网格布局、渐变滤镜、容器查询），在单文件纯原生前提下达到现代现代操作系统级别的 UI 质感。

## 4. 核心组件详细设计

### 4.1 动态背景光斑 (Dynamic Ambient Canvas)
- **实现原理**：在 `body::before` 或背景容器内配置 3~4 个独立层级的 `radial-gradient` 伪元素。
- **动效规律**：
  - 光斑 1（左上）：横向 20% / 纵向 15% 缓慢椭圆运动（时长 55s）
  - 光斑 2（右上）：反向对角浮动（时长 65s）
  - 光斑 3（正中偏下）：缓慢膨胀收缩微动（时长 45s）
- **无障碍降级**：检测 `@media (prefers-reduced-motion: reduce)`，自动关闭 `animation`，保持静态柔和渐变。

---

### 4.2 聚合搜索框 (Omni Search Bar)

#### 视觉参数
- **外形**：大圆角胶囊（`border-radius: 9999px` 或 `28px`），高度 `56px`（桌面端推荐 `60px`），最大宽度 `680px`。
- **材质**：`--glass-bg` + `backdrop-filter: blur(20px)` + `--glass-border`。
- **组成结构**：
  1. **左侧引擎指示器 (Engine Trigger / Selector)**：
     - 包含引擎图标/缩写标签 + 下拉指示角标（`▾`）。
     - 支持点击弹出引擎切换浮层，或在输入框内按 `Tab` 循环切换当前选中的引擎。
     - 当前引擎带有微高亮底色（`--accent-light`）与品牌主色文字。
  2. **中部输入区 (Search Input)**：
     - 无边框透明背景输入框，字号 `16px`，占位文本 `在此搜索... 按 Tab 换源`。
     - 自动聚焦或按 `/` 键即刻唤醒。
  3. **右侧直达与快捷键提示 (Action Badges)**：
     - 极简圆角快捷键徽章 `↵ Enter` 或搜索放大镜图标。
- **交互状态**：
  - **Hover 态**：边框微亮，阴影小幅扩展。
  - **Focus-within 态**：边框过渡到 `--accent`，外围施加 `0 0 0 3px rgba(99, 102, 241, 0.2)` 聚焦光环。

---

### 4.3 网址分类与卡片网格 (Categorized Grid Cards)

#### 分类栏设计 (Section Header)
- **文字样式**：字号 `13px`，字重 `600`，字距 `letter-spacing: 0.08em`，颜色 `--text-2`。
- **装饰**：分类名称左侧带有 3px 宽的小色条或前置小点，右侧为半透明柔和分割线。

#### 网址卡片 (Site Card)
- **网格规范**：
  - 容器网格：`grid-template-columns: repeat(auto-fill, minmax(140px, 1fr))`。
  - 间距：`gap: 8px 10px`。
- **卡片规格**：
  - 尺寸：高度 `40px`，圆角 `11px`。
  - 排版布局：紧凑单行水平 Flex 居中对齐（左侧 24px 精致图标容器，右侧站点标题）。
  - 内边距：`padding: 0 10px`。
  - 描述展示：常态隐藏，鼠标移入（Hover）时通过毛玻璃浮动气泡（Tooltip）即时浮现说明与域名。
- **三级图标策略 (Icon Strategy)**：
  1. **Level 1**：配置了 `icon` 显式图片地址，直接加载渲染（16×16px）。
  2. **Level 2**：未配置时自动请求 `https://<domain>/favicon.ico`。
  3. **Level 3 降级**：图片加载 `onerror` 时，平滑切换为 **首字母彩色圆形/圆角徽章**（通过站名字符 Hash 算法生成固定的高饱和柔和渐变底色，文字白色 11px 粗体）。
- **动效规范**：
  - `transition: transform 0.2s cubic-bezier(0.34, 1.56, 0.64, 1), box-shadow 0.2s, background-color 0.2s`
  - **Hover**：`transform: translateY(-2px);` 阴影加深，高光边框显现，上方浮现说明 Tooltip 气泡。
  - **Active (按下)**：`transform: scale(0.98) translateY(0);`。

---

### 4.4 三态主题切换器 (Tri-State Theme Switcher)

- **位置**：页面右上角悬浮固定（`position: fixed; top: 20px; right: 24px; z-index: 100;`）。
- **外观**：`40px x 40px` 正圆玻璃胶囊按钮，居中呈现 SVG 矢量图标。
- **三态循环与图标映射**：
  - `auto` (跟随系统)：显示 `🌗` 或系统/自适应双色图标 + tooltip `跟随系统`
  - `light` (浅色模式)：显示 `☀️` 太阳高光图标 + tooltip `浅色模式`
  - `dark` (深色模式)：显示 `🌙` 月牙夜间图标 + tooltip `深色模式`
- **微交互**：点击时图标带 `rotate(360deg)` 顺时针旋转切换动效（`0.35s ease`）。

## 5. 交互行为全景 (Interaction Specs)

| 触发场景 | 快捷键 / 操作 | 交互反馈与业务行为 |
|---|---|---|
| **页面初次载入** | 页面加载完成 (`DOMContentLoaded`) | 1. 自动执行 `searchInput.focus()`<br>2. 从 `localStorage` 读取 `nav-engine` 与 `nav-theme` 状态并应用<br>3. 若为 auto 态，注册 `window.matchMedia('(prefers-color-scheme: dark)')` 监听 |
| **全局快速聚焦** | 按下 `/` 键 | 阻止浏览器默认行为，页面平滑滚动至顶部并将光标聚焦至搜索框，选中全部文本 |
| **切换搜索引擎** | 在搜索框内按 `Tab` 键 | 阻止默认焦点跳出，按引擎列表索引循环选中下一个引擎（如 Google → Bing → 百度 → DuckDuckGo → Google），更新提示与左侧标签 |
| **点击切换引擎** | 点击搜索框左侧引擎名/图标 | 弹出下拉菜单，或直接轮换下一个引擎，同步保存到 `localStorage` |
| **执行搜索** | 在搜索框内按 `Enter` 键 | 提取当前输入内容 `q`：<br>1. 若为空，聚焦不跳转<br>2. 若非空，根据当前选定引擎模板替换 `%s`，在新标签页打开（`window.open(url, '_blank')`） |
| **打开网址** | 单击任意网址卡片 | 新标签页打开（`target="_blank" rel="noopener noreferrer"`） |
| **切换主题** | 点击右上角主题按钮 | 状态按 `auto` → `light` → `dark` → `auto` 循环轮替，即时切换 DOM 属性 `data-theme` 并存入 `localStorage` |

## 6. 响应式与断点设计 (Responsive Layout)

### 6.1 桌面宽屏模式 (`≥ 1024px`)
- 主容器宽度：`max-width: 1120px`，页面居中，顶部间隙 `80px`。
- 搜索框：宽度 `680px`，居中显要位置。
- 分类网格：每行 5~7 列，卡片宽约 `170px`。

### 6.2 平板/中屏模式 (`768px ~ 1023px`)
- 主容器左右内边距：`24px`。
- 搜索框：宽度 `100%`（最大 `600px`）。
- 分类网格：自适应每行 3~4 列。

### 6.3 移动端模式 (`< 768px`)
- 顶部间隙缩减至 `32px`，搜索框高度 `50px`，文字字号 `15px`。
- 分类网格：`grid-template-columns: repeat(2, 1fr)`（每行固定 2 列双排卡片）。
- 卡片间距缩至 `10px`，去除复杂 hover 动效，保留点击态涟漪/缩放反馈。

## 7. 异常状态与鲁棒性设计 (Edge Cases & Fallback)

1. **Favicon 跨域 / 404 / 断网**：
   - 监听 `img.onerror` 事件，加载失败时自动销毁 `img`，展示预先生成的首字母渐变彩色占位块（例如 GitHub 渲染为带 "G" 的靛蓝圆形徽章），不造成任何布局抖动。
2. **纯离线运行环境 (`file://` 协议断网使用)**：
   - 页面所需样式、脚本、SVG 矢量图标全部内嵌在 `index.html`。
   - 断网打开时，除外部 favicon 失败触发降级外，所有搜索跳转引擎选择、卡片点击、主题切换、快捷键响应 100% 顺畅可用。
3. **极长网址/超长标题截断**：
   - 站点名称应用 `text-overflow: ellipsis; white-space: nowrap; overflow: hidden;`，悬停在卡片上时通过原生 `title` 属性显示完整名称与描述。
